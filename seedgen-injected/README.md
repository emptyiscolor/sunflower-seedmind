# Injected SeedGen Component

This component is injected to the CP container.

## Service

It will starts a service once the container is ready.

1. Compile: Compile the harness and return available harnesses if the compiling ends.
2. Locate(harness, function_name): locate the function, return the filename and line information.
3. View(harness, function_name): view the function source code.
